# Figures

Suggested first figure: **From replication to narrative integration**.

Conceptual structure:

```text
REPLICATION

RCT 1 ──────────┐
                ├──→ Target claim
RCT 2 ──────────┘
     independent replication


NARRATIVE INTEGRATION

Prior evidence ───────────┐
Pharmacokinetics ─────────┤
Exposure–response ────────┤
Clinical evidence ────────┼──→ Integrated argument ──→ Target claim
Safety ───────────────────┤
Immunogenicity ───────────┤
Mechanistic evidence ─────┘

Each connection contains an inferential assumption.
```

The repository should preferentially store source files for figures in an editable vector format, together with an exported SVG or PDF.
